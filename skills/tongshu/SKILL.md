# 農民曆擇日 (tongshu)

## 用法(必跑 script)

單日查詢:
```bash
python3 scripts/almanac.py --date 2026-06-20
```
區間擇日(自動剔除沖當事人生肖之日):
```bash
python3 scripts/almanac.py --from 2026-06-15 --to 2026-07-15 --event 嫁娶 --shengxiao 馬 --shengxiao 鼠
```
- `--event` 用詞須符合通書用語:嫁娶/納采/訂盟/移徙(搬家)/入宅/開市(開業)/動土/安床/出行/交易/立券(簽約)/安葬/祭祀/祈福/修造
- 涉及多位當事人(如新人雙方)時,`--shengxiao` 全部列入

## 擇日輸出規則(固定)

1. 每個候選日**必列**:農曆日期、沖(生肖)、煞方、吉時
2. 吉時要再過濾:**沖當事人生肖的吉時不可推薦**(吉時欄已附沖生肖)
3. 優先序:宜含用事 → 不沖生肖 → 建除吉日(成/開/定/危依事而異)→ 吉時可用
4. 最終取捨參考 `references/zeri-methods.md`(三合擇日、造命歌、建除吉凶、方位用法)

## 結論原則

論生不論死、論命不斷命;擇日為趨吉避凶之參考,重大日期仍提醒配合實際行程。
