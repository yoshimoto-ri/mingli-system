# 命理系統主控 (mingli-master)

WEBHOOK_URL: (未設定,請依 README.md 部署 Apps Script 後填入你自己的網址,或在 config.json 設定)

> ⚠️ 首次使用者:本 skill 需要你自己部署 Google Apps Script 端點才能寫入 Sheets。
> 步驟見專案根目錄 README.md「部署 Google Sheets 寫入端點」章節。
> 部署後,把網址填入下面這行,或建立 `config.json`(見 config.example.json)。

## 觸發條件(符合任一即啟動本skill)
- 使用者說「算命」「看命盤」「問運勢」「做完整分析」
- 使用者問近期流年流月、重大決策、人生方向
- 其他 skill 完成單項分析後,使用者想要「綜合解讀」

## 第一步:確認需求(FANzR追問原則)

**追問控制在1-4個最關鍵問題,不一次拋出長問卷,不靜默代填預設值。**

### 步驟一:先問這次最想看什麼
> 「請問你想：
> A) 🎴 問一件事的吉凶走向 → 易經卜卦（三個月內,最省 token）
> B) ☯️ 看流年運勢/個人格局 → 紫微斗數
> C) ⭐ 看星象時機/靈魂課題 → 西洋占星
> D) 🔮 紫微+占星交叉比對
> E) 📊 重大決策綜合全套（分段進行）」

### 步驟二:確認是否有現成命盤
- 若使用者已有排盤軟體結果/截圖 → **優先基於現有盤解讀**,不重新換算
- 若無 → 再收集出生資料

### 步驟三:補充出生資料(缺什麼問什麼,不重複問已有的)
依序:出生日期(陽曆) → 出生時間 → 性別 → 出生地/時區

### 步驟四:確認口徑爭議點(有疑義才問)
子時換日規則、閏月歸屬、是否沿用某軟體口徑

**要算的事**:流年流月流日/姻緣/事業/金錢房產/家人關係/學習考試/健康/合作/婚姻/更名/尋物/擇日/其他問事

**缺資料降級規則**:
| 缺 | 處理 |
|---|---|
| 出生時辰 | 不排紫微;占星僅排日盤(無宮位/上升,須註明);改以易經+姓名學為主 |
| 出生地 | 詢問;不可得則用使用者所在地時區、不做真太陽時,註明誤差(時辰交界±30分特別警示) |
| 完整生日 | 僅用易經卜卦+姓名學 |
| 中文名 | 東方姓名學略過,僅做西方靈數 |

不論出生於哪個國家,一律以**出生地當地時間**輸入,時區與 DST 由 skill 自動處理。

## 第二步:調度運算(全部跑 script,嚴禁心算)

| 需求 | 調用 skill |
|---|---|
| 曆法/農曆/時辰 | calendar-converter(一切東方系統的時間基準) |
| 本命+大限流年 | ziwei(內建真太陽時與子時換日) |
| 占星本命/比對 | western-astrology(注意:占星不做真太陽時) |
| 問事吉凶 | iching(以系統當下時間起卦;**有提供生辰則加 --birthdate**,引擎自動計算命主生肖年支五行與卦象連結) |
| 擇日 | tongshu(必列沖煞生肖+吉時)+ western-astrology 擇日模式 |
| 姓名/更名 | name-numerology(康熙筆畫先查證)+ wuxing(喜用神) |
| 五行底層 | wuxing |

## 第三步:解讀程序(對應 5a–5f)

a. 以**系統當下時間**(使用者當地)為流年流月流日判斷基準
b. 簡述命主個性、家庭背景與父母個性;掃描十二宮指出過去或未來可能的重大事件(早婚、傷病、財務、手足等),**好壞並陳**
c. **紫微與占星比對**所問之事:宮位主題對照(10宮≈官祿、7宮≈夫妻、4宮≈田宅、2宮≈財帛、6宮≈疾厄、9宮≈遷移),一致處加強信度、分歧處並陳
d. **姓名學+易經**:以當事人姓名與當下時間起卦,論問事吉凶與可能性
e. **擇日**:列出候選日之沖煞生肖與吉時;吉時再避當事人生肖
f. 鐵律:**論生不論死**(不斷死亡壽限絕症)、**論命不斷命**(不下宿命定論,給趨勢+條件+建議);健康一律提醒就醫

報告格式依 `references/report-template.md`。

## 第四步:存檔(必做,每次報告結束後強制執行,不可省略)

報告完成後,組摘要 JSON 並執行:
```bash
python3 scripts/save_to_sheets.py --json '{"姓名":"...","性別":"...","出生時間":"...","出生地":"...","問事類別":"...","紫微摘要":"...","占星摘要":"...","易經摘要":"...","姓名學摘要":"...","擇日摘要":"...","結論":"..."}'
```
- 各摘要 ≤100 字;未用到的系統留空字串
- URL 自動讀本檔 WEBHOOK_URL 行;寫入成功告知使用者「已存入 Google Drive/命理系統」
- 失敗則告知並附完整摘要文字,請使用者手動保存

### PDF 匯出(使用者要求時執行)
```bash
python3 scripts/export_pdf.py --name "王小明" --date "2026-06-13" --content "報告全文..."
```
- 檔名自動為「姓名_日期.pdf」
- 中文字型使用 NotoSerifCJK,自動嵌入
- 產生後用 present_files 讓使用者下載
- 如需上傳 Google Drive「命理系統」資料夾,加 --webhook URL(需先在 Apps Script 加 upload_pdf 處理器,或請使用者手動上傳)

⚠️ **寫入鐵則**:報告六節內容全部輸出完畢後,無論使用者有無要求,**必須自動執行 save_to_sheets.py**。不可等待使用者提醒,不可省略。寫入成功後告知「✓ 已存入 Google Drive／命理系統」。
