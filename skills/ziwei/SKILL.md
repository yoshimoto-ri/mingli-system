# 紫微斗數 (ziwei)

排盤引擎:py-iztro + 獨立規則引擎 `ziwei_rules.py` 交叉驗證(內建真太陽時 + DST + 子時換日規則,與 calendar-converter 一致)。

**口徑(門派)固定在 `school.json`**:門派(全書/中州)、年界(正月初一)、閏月規則、四化覆寫、亮度覆寫。每次輸出開頭都會回報「口徑」,解讀時須在報告中註明。

## 流程

### 1. 收集資料(缺任何一項必須先問,不可預設或跳過)

| 欄位 | 說明 | 缺漏處理 |
|---|---|---|
| **性別** | 影響大限順逆行,排盤前**必問**,絕對不可假設或省略 | 直接問「請問性別是男還是女？」|
| 出生年月日 | 陽曆當地時間 | 必填 |
| 出生時辰 | 當地時間 HH:MM | 缺時辰 → 告知無法排紫微,建議改用易經或姓名學 |
| 出生地 | 用於時區與經度 | 缺地點 → 詢問;不可得則用使用者所在地並註明誤差 |

⚠️ **性別鐵則**:男女命大限起算方向相反(陽男陰女順行/陰男陽女逆行),性別錯誤會導致整張命盤大限全部排錯。使用者未提供性別時,**排盤前必須先問清楚,不可繼續**。

### 2. 排盤(必須跑 script)

```bash
python3 scripts/chart.py --date "1990-08-15 23:15" --tz "Asia/Taipei" --lon 121.56 --gender 女 --target "2026-06-11"
```

- `--target`:問事/流年的目標日,預設今天(系統當下時間)
- **全年流月一律用 `--months 2027`**(輸出該農曆年正月~臘月,含閏月),**禁止自行挑日期取樣**
- 若已有 calendar-converter 的結果,可用 `--chart-date YYYY-MM-DD --time-index N` 直接排,免重複校正

### 2.5 排盤閘門(解盤前必過)

| 檢查 | 不過時 |
|---|---|
| `交叉驗證.結果` = 通過 | 主星、命身宮、五行局、宮干、生年四化有差異 → **禁止解盤**,回報差異 |
| `時辰交界警示` 不存在 | 存在 → 先向當事人確認出生時間,或兩個時辰並看 |
| `運限.流月.校正` | 有值代表引擎原值已被校正,一律以校正後為準 |

亮度一律引用引擎輸出(對照表 `references/brightness-table.md`),不得自行改寫「廟/旺」。

### 3. 解讀(依需要讀 references)

- `references/brightness-table.md` — 本系統實際使用的星曜亮度表(引擎口徑)
- `references/palaces.md` — 十二宮意義、三方四正、身宮、借星安宮
- `references/major-stars.md` — 十四主星性質與廟陷
- `references/minor-stars-sihua.md` — 六吉六煞、祿存天馬、四化意義與十干四化
- `references/interpretation.md` — 三合派/中州派解讀法、標準論命程序、論命二原則(**必讀**)

### 4. 解讀輸出格式(固定範本)

一、**基本資料**:姓名/性別/生辰、生肖(括號註明今年虛歲)、流年太歲提示(值太歲偏沖/沖太歲正沖,引擎已算好直接引用)
二、**個性與家庭背景**:命宮三方四正論個性;父母宮+田宅宮論家庭與父母;掃描十二宮指出過去/未來可能的重大事件,好壞並陳
三、**十二宮概述**:逐宮簡述(用此標題)
四、**大限走勢**:每個大限必須加註西元年區間,引擎輸出已含(如 53-62歲(2042-2051年)),直接引用
五、**流年/問事分析**:流月一律以引擎輸出的「流月農曆月份」標示(如:農曆四月),嚴禁以流月干支自行換算月份;依本命→大限→流年四化→流月流日順序論應期
六、**結論與建議**:遵守論生不論死、論命不斷命

### 5. 解讀要領

a. 以系統當下時間(或使用者指定 target)為判斷基準
b. 先簡述命主個性(命宮三方四正)、家庭背景與父母(父母宮、田宅宮)、過去/未來可能的重大事件(十二宮逐一掃描:早婚、傷病、財務起伏、手足緣分等,好壞並陳)
c. 針對所問之事,找對應宮位(姻緣→夫妻宮、事業→官祿宮、金錢房產→財帛+田宅、考試→命+父母(文書)、健康→疾厄、合作→交友/兄弟、家人→六親宮),看本命格局 + 大限 + 流年四化引動,客觀說明發展趨勢
d. 與西洋占星比對時,陳述兩系統一致與分歧之處(占星 skill 完成後)
e. 結論遵守二原則:**論生不論死、論命不斷命**(見 interpretation.md)

### 6. 解讀檢查清單(每次必跑,報告附「已檢查項目」)

1. **層級標籤**:提到宮名一律加【本】【限】【年】【月】,例:「巨門忌坐【本】福德=【年】田宅,沖【本】財帛」。引擎的 `坐`/`沖`/`宮位疊盤` 已標好,直接引用
2. **化忌必看坐、沖兩宮**:生年、大限、流年、流月四化,每顆化忌都寫出坐宮與沖宮
3. **宮內星曜全列**:所論宮位的主星、輔星、六煞、空劫、祿存天馬全部列出,不只看主星(例:祿存逢地空=財來財去)
4. **流曜**:流年羊陀、魁鉞、昌曲、祿馬(`流年流曜`)落在哪一宮,特別是流羊/流陀入流年命宮、財帛、疾厄
5. **雙忌/祿忌交會**:同一宮或同一顆星被兩層四化引動時(例:大限忌+流月忌同星),標為重點月份
6. **流月表逐月檢查**:`--months` 每個月的四化坐/沖,不能只挑祿權
7. **用詞**:祿忌同星稱「得失並見」,不稱「化解」
