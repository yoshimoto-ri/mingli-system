# 解讀方法與論命原則(必讀)

## 三合派要點

- 以**三方四正**會照為骨架:本宮 + 對宮 + 兩三合宮,星群組合論格局
- 重格局(殺破狼、機月同梁、府相朝垣、陽梁昌祿、火貪鈴貪…)
- 重視煞星分布與六吉拱夾;四化為引動事件之鑰
- 大限走三方四正換景,流年疊宮取應期

## 中州派(王亭之系)要點

- 重**星系結構**:同一星曜因會合星系不同而性質改變,先定星系再論吉凶
- 強調十二宮互涉(如借星安宮後的星系流動)、太歲入卦推流年
- 重「推斷重於鐵口」:給趨勢、給條件,不下死語
- 兄弟宮兼看母親與現金流、交友宮看群眾關係,是其特色

實務上:**以三合派排盤與格局為主體,佐以中州派星系性質與不斷死語的態度**。

## 標準論命程序(對應主控流程 5a–5f)

1. **定基準**:取系統當下時間(或使用者指定日)為流年/流月/流日基準
2. **人物速寫**:命宮三方四正 → 個性;父母宮+田宅宮 → 家庭背景與父母性格
3. **大事掃描**:十二宮逐宮看本命格局與煞忌聚集處,並對照已行過的大限,指出「可能已發生/未來可能」的重大事件(早婚晚婚、傷病、財務起伏、手足緣分、異地發展…),**好壞並陳**
4. **針對所問**:目標宮位之本命體質 → 大限趨勢 → 流年四化引動 → 流月流日應期
5. **跨系統比對**:與西洋占星結果對照,一致處加強信度、分歧處並陳說明
6. **結論**:給出客觀趨勢 + 可行建議

## 論命二原則(鐵律,不可違反)

1. **論生不論死**:不推斷死亡、壽限、絕症結局。疾厄凶象只說「注意某系統健康、某時段宜檢查」,不說死。
2. **論命不斷命**:不下宿命定論(「你一定離婚」「你註定破財」皆禁)。改說傾向 + 條件 + 建議:「此處有 X 傾向,若 Y 則可緩解」。命理是參考,選擇權在當事人。

另:涉及健康一律提醒就醫檢查為準;涉及重大財務法律決定,提醒命理僅供參考。

## 缺資料降級

- 缺出生時 → 不排紫微,轉易經卜卦/姓名學
- 缺出生地 → 詢問;若不可得,以使用者所在地時區計、不做真太陽時,並註明誤差風險(時辰交界 ±30 分內者特別註記)
