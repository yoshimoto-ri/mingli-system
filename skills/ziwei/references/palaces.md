# 十二宮意義

## 各宮主管事項

| 宮位 | 主管 | 延伸 |
|---|---|---|
| 命宮 | 個性、格局、一生主軸 | 與遷移宮對照看內外 |
| 兄弟宮 | 手足、母親(中州派)、現金流量 | 合作夥伴的庫位 |
| 夫妻宮 | 婚姻、感情模式、配偶特質 | 早婚晚婚、聚少離多 |
| 子女宮 | 子女、性、桃花、合夥下游 | 意外之災亦觀此宮 |
| 財帛宮 | 賺錢方式、財運、價值觀 | 與福德對照看財源心態 |
| 疾厄宮 | 健康、體質、災厄 | 配合五行局與星曜五行看病位 |
| 遷移宮 | 外出、外緣、社會際遇 | 適不適合離鄉發展 |
| 交友宮(僕役) | 朋友、部屬、群眾關係 | 合作對象品質 |
| 官祿宮(事業) | 事業、工作型態、考運 | 學生看學業 |
| 田宅宮 | 不動產、家庭環境、財庫 | 祖業、居住品質 |
| 福德宮 | 精神生活、福分、嗜好 | 壽元、晚年心境、財帛之源 |
| 父母宮 | 父母、長輩、文書、相貌 | 公家機關緣、考試文書 |

## 三方四正

- 任一宮的**三方**:該宮 + 對宮起順逆各四位(即三合方:申子辰、寅午戌、巳酉丑、亥卯未)
- **四正** = 三方 + 對宮。論一宮吉凶必看三方四正會照之星,不可單看本宮
- 對宮關係:命↔遷、兄↔友、夫↔官、子↔田、財↔福、疾↔父

## 身宮

- 身宮為後天著力點,35 歲後影響漸重;落於命/夫妻/財帛/遷移/官祿/福德六宮之一
- 命好身差:先盛後衰之象;命差身好:後天可補

## 借星安宮

本宮無主星時,借**對宮**主星論之,但力量約七成,且帶「外來、不穩」性質。

## 問事對應速查

流年流月流日→疊宮看流命;姻緣婚姻→夫妻;事業→官祿;金錢→財帛;房產→田宅;家人→父母/兄弟/子女;學習考試→官祿+父母(文書);健康→疾厄;合作→兄弟+交友;更名→命+福德;尋物→田宅+遷移方位。
