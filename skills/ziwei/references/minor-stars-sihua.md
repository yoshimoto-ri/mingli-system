# 輔星、煞星與四化

## 六吉星

- **左輔/右弼**:助力、貴人、平輩相助;夾命或會命最佳。入夫妻宮防第三者介入(僅提醒)。
- **文昌/文曲**:科甲、文書、才藝;昌主正途功名、曲主口才才藝。昌曲化忌防文書失誤、感情波折。
- **天魁/天鉞**:天乙貴人,長輩貴人、機會;魁為陽貴(明)、鉞為陰貴(暗)。

## 祿存、天馬

- **祿存**:固定財祿、保守儲蓄;必被擎羊陀羅前後夾,孤剋自守。
- **天馬**:驛馬、變動、外出;祿存或化祿同會為「祿馬交馳」,動中得財。

## 六煞星

- **擎羊**:刑傷、衝勁、競爭;廟(辰戌丑未)主權威帶刑,陷主血光是非。
- **陀羅**:拖延、糾纏、暗耗;事多反覆磨折。
- **火星/鈴星**:急躁、突發;獨坐多衝突,**會貪狼反成橫發格**。
- **地空/地劫**:精神面與物質面的破耗、空想;利哲學宗教創意,不利投機。

## 四化(動態引動,論運核心)

| 化 | 意義 | 論事用法 |
|---|---|---|
| 化祿 | 緣起、財祿、順遂 | 該宮之事有機會、有資源 |
| 化權 | 掌控、擴張、奔忙 | 主導權增,但帶爭 |
| 化科 | 名聲、貴人、緩解 | 利考試文書名譽,逢凶可解 |
| 化忌 | 執著、虧欠、阻滯 | 該宮之事費心糾結,為全盤癥結點 |

## 疊宮論法(流年流月流日)

1. 流年地支即流年命宮所在 → 重排流年十二宮
2. 看「流年命宮」疊在本命何宮:疊本命財帛則該年主題在財,依此類推
3. 引動順序:本命四化(因)→ 大限四化(十年趨勢)→ 流年四化(該年應期)→ 流月流日(細部時點)
4. 同一星疊祿又逢忌 = 雙象並存,先得後失或得中有礙,如實並陳
