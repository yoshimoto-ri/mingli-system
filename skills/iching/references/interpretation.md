# 卜卦解讀參考

## 文王卦斷法

### 1. 取用神(問什麼取什麼)
| 所問 | 用神 |
|---|---|
| 自己/考試成績文書 | 世爻/父母爻 |
| 財運、買賣、妻 | 妻財爻 |
| 事業、官司、夫、上司 | 官鬼爻 |
| 子女、寵物、解憂、醫藥 | 子孫爻 |
| 兄弟朋友、合夥人、競爭者 | 兄弟爻 |
| 父母長輩、房屋車輛、合約文書 | 父母爻 |
| 對方、所問之事主體 | 應爻 |
| 尋物 | 視物取六親(財物=妻財),看其所臨之宮卦方位與爻位高低 |

### 2. 旺衰(用神得力與否)
- 月建、日辰生扶用神=旺;沖剋=衰;日辰沖用神=暗動或受制
- 用神旺相+發動生世=吉速;休囚+受剋+空亡=難成

### 3. 動變
- 動爻是事件引動點:動爻生用神助吉,剋用神主阻
- 變爻回頭生=漸好;回頭剋=先成後敗
- 靜卦以月日論;多爻動取最上動爻與用神關係為主

### 4. 旬空與應期
- 用神旬空:事未實、心不定;出空之日(值日/沖空)為應期
- 應期常取:用神值日、合日、沖日;近事看日、遠事看月

### 5. 六獸(性質修飾,非吉凶主體)
青龍=喜慶酒色|朱雀=口舌文書|勾陳=田土牽連遲滯|螣蛇=怪異虛驚|白虎=疾病刑傷|玄武=暗昧盜失曖昧

## 梅花易數斷法
1. **體用**:不動之卦為體(自己),動爻之卦為用(事/對方)
2. 用生體=吉,體剋用=可成但費力,用剋體=凶阻,體生用=耗洩,比和=順
3. **互卦**看過程,**變卦**看結果;體卦旺(得月令)更有力
4. 外應可參:起卦當下見聞之吉凶兆
5. 尋物方位:用卦後天八卦方位(乾西北/坎北/艮東北/震東/巽東南/離南/坤西南/兌西);參酌卦象(坎水邊、離爐灶明處、艮山牆角、巽繩木高處)

## 共同原則
卦不妄斷,證據在卦中;吉凶並陳,給條件與建議,不下死語。

## 命主五行與卦象連結(有提供生辰時適用)

### 命主年支五行作為判斷基準
- 引擎輸出「命主年支五行」與「生肖」,解卦時作為命主五行屬性
- 例:命主屬馬(午火) → 用神得火爻生助=有利;遇水爻=受剋需謹慎

### 變卦五行推論格式
1. **本卦**:事情現況與起始格局
2. **動爻五行**:引動的力量屬性,與命主五行對照:
   - 動爻生命主五行 → 外力助推,事情有人幫
   - 動爻剋命主五行 → 有阻力或競爭壓力
   - 命主五行剋動爻 → 命主可掌控局面
   - 比和 → 平順,同類相聚
3. **互卦**:事情發展中段過程
4. **變卦**:事情最終走向與結果
   - 變卦五行生本卦五行 → 結果轉好
   - 變卦五行剋本卦五行 → 結果有變數或轉差
   - 比和 → 結果與現況相近,無大起伏

### 綜合判讀順序
本卦格局(現況)→ 動爻性質+與命主五行生剋 → 互卦過程 → 變卦結果五行 → 給出「三個月內」的趨勢結論與建議
