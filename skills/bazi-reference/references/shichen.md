## 驗證範例
- 1975-10-01 **20:00** → 查表 19:00-20:59 → **戌時 / index=10**
- 1975-10-01 **21:00** → 查表 21:00-22:59 → **亥時 / index=11**
- 某日 **23:15** → 查表 23:00-23:59 → 晚子時 → 排盤用**次日**子時
- 日干庚 + 戌時 → 查時干表 乙/庚列 戌時欄 → **丙戌**
